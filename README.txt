Crypto 4View Android app project.
Default markets: USDT/USD, LTC/USDT, HMSTR/USDT, SPCXB/USDT.
Includes native notification permission and a foreground monitoring service polling Binance every 30 seconds.
Open the folder in Android Studio, sync Gradle, then Build > Build APK(s).
After installing, allow notifications. If alerts must run reliably in background, disable battery optimization for the app.
